# 🧩 حل‌کننده‌ی سودوکو با پایتون

یک حل‌کننده‌ی Sudoku با زبان Python که برای حل جدول‌های ۹×۹ از ترکیب **تکنیک‌های حل منطقی، حذف کاندیداها و الگوریتم Backtracking بازگشتی** استفاده می‌کند.

هدف این پروژه، پیاده‌سازی یک حل‌کننده‌ی Sudoku و تمرین مفاهیم الگوریتمی و مهندسی نرم‌افزار مانند **Recursion، Backtracking، Constraint Satisfaction و Heuristic Search** است.

---

## ⚙️ نحوه‌ی کار برنامه

الگوریتم حل Sudoku در این پروژه به‌طور کلی دو مرحله دارد:

### ۱. کاهش فضای جستجو

ابتدا برای هر خانه‌ی خالی، تمام اعداد ممکن محاسبه می‌شوند.

برای تعیین اعداد ممکن، وضعیت موارد زیر بررسی می‌شود:

* سطر خانه
* ستون خانه
* مربع ۳×۳ مربوط به خانه

برای مثال، اگر کاندیداهای یک خانه فقط شامل عدد زیر باشند:

</div>

```python
[4]
```

<div dir="rtl">

مشخص است که مقدار آن خانه باید `4` باشد.

این فرآیند چندین بار تکرار می‌شود تا زمانی که دیگر نتوان با تکنیک‌های موجود، اطلاعات جدیدی به جدول اضافه کرد.

---

## 🧠 تکنیک‌های حل

### Single Candidate

اگر یک خانه فقط یک کاندیدای ممکن داشته باشد، همان عدد در خانه قرار می‌گیرد.

این منطق در تابع <code dir="ltr">imputer()</code> پیاده‌سازی شده است.

---

### Hidden Single

در بعضی شرایط، یک عدد ممکن است در چند خانه به عنوان کاندیدا وجود داشته باشد، اما در یک سطر، ستون یا مربع ۳×۳ فقط در **یک خانه** قابل قرار گرفتن باشد.

در این حالت آن عدد باید در همان خانه قرار بگیرد.

توابع مربوط به این بخش شامل موارد زیر هستند:

</div>

```text
where_the_number()
check_alone_number()
```

<div dir="rtl">

---

### حذف کاندیداها

پس از قرار گرفتن یک عدد در جدول، آن عدد دیگر نمی‌تواند در خانه‌های مرتبط قرار بگیرد.

بنابراین از کاندیداهای خانه‌های موجود در:

* همان سطر
* همان ستون
* همان مربع ۳×۳

حذف می‌شود.

این کار توسط <code dir="ltr">numb_remover()</code> انجام می‌شود.

---

### بررسی دو موقعیت ممکن

تابع <code dir="ltr">only_two_detector()</code> شرایطی را بررسی می‌کند که یک عدد مشخص تنها در دو موقعیت از یک واحد قرار گرفته باشد و می‌تواند به حذف برخی کاندیداهای غیرضروری کمک کند.

---

## 🔄 Backtracking

اگر تکنیک‌های منطقی نتوانند جدول را به‌طور کامل حل کنند، برنامه وارد مرحله‌ی **Backtracking** می‌شود.

در این مرحله، الگوریتم یک خانه را انتخاب می‌کند و کاندیداهای آن را یکی‌یکی امتحان می‌کند.

برای مثال:

</div>

```text
Cell A → [1, 4, 7]
Cell B → [2, 9]
Cell C → [3, 5, 6, 8]
```

<div dir="rtl">

به جای انتخاب تصادفی، خانه‌ای انتخاب می‌شود که کمترین تعداد کاندیدا را دارد.

در مثال بالا، خانه‌ی <code dir="ltr">B</code> انتخاب می‌شود.

---

## 🎯 انتخاب بهترین خانه برای حدس

تابع <code dir="ltr">min_possible()</code> خانه‌ای را انتخاب می‌کند که کمترین تعداد کاندیدا را دارد.

این روش با مفهوم **Minimum Remaining Values (MRV)** در مسائل Constraint Satisfaction مرتبط است.

برای مثال:

</div>

```text
[1, 4, 7] → 3 candidates
[2, 9]     → 2 candidates  ← انتخاب می‌شود
[3, 5, 6]  → 3 candidates
```

<div dir="rtl">

دلیل استفاده از این روش این است که انتخاب یک خانه‌ی محدودتر، احتمال رسیدن سریع‌تر به یک وضعیت نامعتبر را افزایش می‌دهد و در نتیجه تعداد شاخه‌های غیرضروری در فضای جستجو کاهش پیدا می‌کند.

---

## 🌳 روند Backtracking

فرآیند کلی به شکل زیر است:

</div>

```text
              Sudoku
                 │
                 ▼
       Generate Candidates
                 │
                 ▼
       Apply Solving Techniques
                 │
          ┌──────┴──────┐
          │             │
       Progress      No Progress
          │             │
          └──────┐      │
                 │      ▼
                 │   Is Solved?
                 │    │     │
                 │   Yes    No
                 │    │     │
                 │    ▼     ▼
                 │  Finish  MRV
                 │          │
                 │          ▼
                 │    Select Cell
                 │          │
                 │          ▼
                 │      Try Candidate
                 │          │
                 │          ▼
                 │    Recursive Call
                 │          │
                 │     ┌────┴────┐
                 │     │         │
                 │   Valid    Invalid
                 │     │         │
                 │     ▼         ▼
                 │   Continue  Backtrack
                 │
                 └─────────────────
```

<div dir="rtl">

اگر یک انتخاب باعث ایجاد وضعیت نامعتبر شود، الگوریتم به مرحله‌ی قبل برمی‌گردد و کاندیدای بعدی را امتحان می‌کند.

این همان مفهوم اصلی **Backtracking** است.

---

## 💾 مدیریت وضعیت

هنگام ایجاد یک شاخه‌ی جدید در Backtracking، برنامه یک کپی از وضعیت فعلی Sudoku و کاندیداها ایجاد می‌کند.

</div>

```python
temp_sudoku = deepcopy(sudoku)
temp_psudoku = deepcopy(p_sudoku)
```

<div dir="rtl">

به این ترتیب، تغییرات یک شاخه روی وضعیت اصلی تأثیر نمی‌گذارد.

اگر شاخه موفق باشد، نتیجه‌ی آن استفاده می‌شود؛ در غیر این صورت وضعیت موقت کنار گذاشته شده و کاندیدای دیگری امتحان می‌شود.
